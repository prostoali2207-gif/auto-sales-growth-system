# Dev fixtures — NOT a qualification set

These are **development** fixtures for the FACT and ID families. They are not
sealed, not held out, and they never produce a QUALIFIED verdict.

- They exercise the **input contract**: does the agent now receive verified
  facts, and the right ones, for the situations that failed in r10.
- They do **not** score agent replies. A scored verdict needs the sealed
  held-out pack and a paid provider run, neither of which happens here.

Nothing in this directory may be copied into a qualification pack. If a case
here ever becomes held-out evidence, it stops being a dev fixture first.

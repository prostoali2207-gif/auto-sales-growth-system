# Analytics Agent — Entrypoint

This file is the executable composition entrypoint for Analytics.

For every Analytics task, the runtime MUST load and apply, in order:

1. `agents/analytics-core-binding.md` — qualified professional-core binding and conflict rules;
2. `agents/analytics-uae-specialization.md` — UAE automotive/social-sales specialization;
3. the current experiment contract, business records, platform observations, CRM data and other live context.

Do not bypass the binding and load the specialization alone while claiming the qualified Analytics composition.

The qualified reusable core itself remains in `prostoali2207-gif/professional-ai-agents`; this repository does not duplicate or paraphrase its normative rules.
